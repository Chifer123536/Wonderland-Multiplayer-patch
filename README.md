# Wonderland Multiplayer Patch

Аддон для мода **The Wonderland 3.x** (Forge 1.20.1), чтобы играть в него компанией.

## Что делает

- Когда одного игрока затягивает в Вондерленд (сон, падение в Незере, любое событие мода), **все остальные игроки попадают в то же измерение рядом с ним**.
- Затянутые проходят через **родной вход мода**: экран загрузки, звук портала, слепота и прочие эффекты этого измерения.
- **Внутри Вондерленда каждый сам по себе.** Порталы, выходы и смерти работают как в оригинале, общего телепорта там нет.
- Фаза мода растёт на **+1 за группу**, а не на +1 за каждого игрока.
- Если мод раскидал игроков по случайным точкам (Endless Library и т.п.), аддон стягивает их к первому.

## Установка

Кидается в `mods` **только тому, кто хостит**: на сервер или игроку, который открывает мир по LAN / e4steam. Остальным игрокам ставить не нужно.

Нужно: Forge 47+ (1.20.1), The Wonderland 3.x.

## Настройки

`config/wonderland_mp-common.toml`:

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `true` | Включить групповой вход |
| `pullDelayTicks` | `10` | Пауза перед тем, как затянуть остальных (20 тиков = 1 сек) |
| `pullFromAnyDimension` | `true` | Тянуть из любого измерения (Незер, Энд) или только из того, откуда затянуло первого |
| `pullSpectators` | `false` | Тянуть наблюдателей |
| `regroup` | `true` | Собирать раскиданных к первому игроку |
| `regroupDistance` | `8` | Дальше скольки блоков игрок считается раскиданным |
| `excludedDimensions` | `[]` | Измерения, вход в которые не тянет остальных, например `["the_wonderland:dreamworld"]` |

## Сборка

Нужен JDK 17+ и установленный Forge 1.20.1 (папка `libraries` лаунчера или сервера). Gradle не нужен.

```powershell
.\build.ps1
.\build.ps1 -Libraries "E:\Minecraft\Server\libraries" -Wonderland "E:\Minecraft\Server\mods\the_wonderland-3.0.3-1.20.1-forge.jar" -Jdk "C:\Program Files\Eclipse Adoptium\jdk-25.0.3.9-hotspot"
```

Результат: `build/libs/wonderland_mp-<версия>.jar`.

Исходники обращаются к Minecraft по SRG-именам (`m_xxxx_`), потому что компилируются прямо против production-jar Forge. Все такие вызовы собраны в `Mc.java`.

## Как устроено

- `GroupEntry` ловит вход игрока снаружи в измерение `the_wonderland:*`. Через `pullDelayTicks` он телепортирует остальных к первому тем же способом, что и сам мод, и при необходимости собирает группу в одну точку.
- `EnterSideEffects` запоминает фазу перед тем, как затянуть группу, и 10 тиков откатывает лишние `+1` от входов затянутых. Команды мода `stopsound @p` из точки прибытия затянутого он переписывает на `@s` этого игрока, чтобы они не срабатывали на первом.
- Переходы внутри Вондерленда, выходы и смерти аддон не трогает.
